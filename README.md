## Featured Projects

### Silent Voices: Bangla Sign Language Recognition
Recognizes 47 Bangla sign language characters (digits, vowels, consonants) from a single hand photo, with confidence scores.
- Fine-tuned **MobileNetV2** on ~43,000 images
- REST API with **Flask**, interface built in **React + Vite**
- Model hosted on HuggingFace, deployed on Vercel and Render

`Python` `TensorFlow` `Flask` `React`
[Live demo](https://silent-voices-three.vercel.app) · [Code](https://github.com/[correct-repo-link])

### CyberSense: Cyberbullying Detection
Classifies harmful online text using classical ML and deep learning, trained on a 64,000-sample dataset.
- Compared 5 ML models plus CNN and LSTM
- NLP pipeline: cleaning, lemmatization, TF-IDF
- Flask REST API with single and batch prediction endpoints

`Python` `scikit-learn` `NLTK` `Flask`
[Live demo](https://cybersense-umber.vercel.app) · [Code](https://github.com/anikaIX/[repo-name])
